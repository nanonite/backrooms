# Reproduction

Run from a checkout containing the unchanged local #100 PLYs. In a fresh
worktree, copy `corridor.ply` and `corridor_clean.ply` from the original
`godot_walk/assets/corridor_splat/` directory; collision and manifests are
already tracked. Do not link writable import files into the original tree.

```bash
godot4 --headless --editor --path godot_walk --import
python scripts/splat_pipeline/bounded_psx_evidence.py inventory
godot4 --headless --fixed-fps 60 --path godot_walk --script res://scripts/sample_bounded_region.gd
python scripts/splat_pipeline/bounded_psx_evidence.py search
godot4 --headless --fixed-fps 60 --path godot_walk --script res://scripts/verify_bounded_psx.gd
godot4 --headless --fixed-fps 60 --path godot_walk --script res://scripts/verify_bounded_psx.gd -- --scene=res://scenes/corridor_psx.tscn
python scripts/splat_pipeline/bounded_psx_evidence.py candidate
python scripts/splat_pipeline/bounded_psx_evidence.py compare
python scripts/splat_pipeline/bounded_psx_evidence.py boundary
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --disable-vsync --script res://scripts/capture_bounded_sweep.gd -- --baseline
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --disable-vsync --script res://scripts/capture_bounded_sweep.gd
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --disable-vsync --script res://scripts/capture_bounded_sweep.gd -- --diagnostic
python scripts/splat_pipeline/bounded_psx_metrics.py
```

Visual capture commands require a real display/GPU. The Python driver sets
DISPLAY=:1 and invokes Vulkan at 1280x720. The documented route positions
are preserved in `route_positions.json`; actual boundary positions are
regenerated by the physics verifier.

Run FPS commands sequentially with other GPU work finished:

```bash
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --disable-vsync --script res://scripts/measure_bounded_fps.gd -- --baseline
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --disable-vsync --script res://scripts/measure_bounded_fps.gd
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --max-fps 60 --disable-vsync --script res://scripts/measure_bounded_fps.gd -- --baseline --capped
DISPLAY=:1 godot4 --path godot_walk --rendering-driver vulkan --resolution 1280x720 --max-fps 60 --disable-vsync --script res://scripts/measure_bounded_fps.gd -- --capped
```
